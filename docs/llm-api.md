# 注册教程

## OpenRouter

> key 为     `sk-or-v1-88271******************ca5328`
> API 端点为 `https://openrouter.ai/api/v1`

1. 创建账户

    访问 [OpenRouter 注册页面](https://openrouter.ai/register) 创建账户，填写邮箱、用户名和密码，完成注册。

    ![OpenRouter 注册](media/llm/openrouter/openrouter-register.png)

2. 进入 Key 页面
    登录后，点击右上角头像，选择 **API Keys** 进入 Key 管理页面。

    ![OpenRouter 进入 Key 页面](media/llm/openrouter/openrouter-api-keys.png)

3. 创建新的 API Key

    点击 **Create New Key** 按钮，输入 Key 名称（如 "YunwoAI"）

    ![OpenRouter 创建 API Key](media/llm/openrouter/openrouter-create-key.png)
    
    然后点击 **Create**。

    ![OpenRouter 新 Key 创建成功](media/llm/openrouter/openrouter-key-created.png)

4. 查看并复制 API Key

    在 Key 管理页面，找到刚刚创建的 API Key，点击右侧的 **复制** 按钮，将其复制到剪贴板。

    ![OpenRouter 复制 API Key](media/llm/openrouter/openrouter-copy-key.png)

## OpenAI Hub

1. 创建账户

    访问 [OpenAI Hub 注册页面](https://api.openai-hub.com/register?aff=3vPh) 创建账户。

    ![OpenAI Hub 创建账户](media/llm/openai-hub/openai-hub-create-account.png)

2. 进入工作台

    登录后，点击 **进入工作台**。

    ![OpenAI Hub 进入工作台](media/llm/openai-hub/openai-hub-enter-workspace.png)

3. 打开 API 页面

    在导航中选择 **API令牌** 选项卡。

    ![OpenAI Hub 打开 API令牌 页面](media/llm/openai-hub/openai-hub-api-tab.png)

4. 选择分组并创建 Key

    选择 **默认分组（Default）** 下，点击 **提交** 创建新的 API Key。

    ![OpenAI Hub 创建 API Key](media/llm/openai-hub/openai-hub-create-key.png)

5. 复制 API Key

    在列表中找到新建的 Key，点击右侧的复制按钮保存。

    ![OpenAI Hub 复制 API Key](media/llm/openai-hub/openai-hub-copy-key.png)

## SiliconFlow（硅基流动）

1. 创建账户

    访问 [硅基流动](https://cloud.siliconflow.cn/i/la6mSlhF) 注册并登录账号。

    ![SiliconFlow 创建账户](media/llm/siliconflow/siliconflow-create-account.png)

2. 打开 API 页面

    在控制台选择 **API密钥** 标签页。

    ![SiliconFlow 打开 API密钥 页面](media/llm/siliconflow/siliconflow-api-tab.png)

3. 创建 API Key

    点击 **新建 API 密钥**，按提示确认创建。

    ![SiliconFlow 创建 API Key](media/llm/siliconflow/siliconflow-create-key.png)

4. 复制 API Key

    在 Key 列表中复制新建的 Key，妥善保存。

    ![SiliconFlow 复制 API Key](media/llm/siliconflow/siliconflow-copy-key.png)

## DeepSeek

1. 创建 API Key

    注册或登录 DeepSeek 开放平台

    ![DeepSeek 注册](media/llm/deepseek/deepseek-register.png)

2. 打开 API Keys 标签并创建

    在 **API Keys** 标签页中，选择创建 API Key。

    ![DeepSeek API Keys 页面](media/llm/deepseek/deepseek-api-keys-tab.png)

3. 复制 API Key

    创建完成后，在列表中复制你的 API Key。

    ![DeepSeek 复制 API Key](media/llm/deepseek/deepseek-copy-key.png)
